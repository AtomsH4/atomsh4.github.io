# 整页兴趣星图验证

本地预览：[整页兴趣星图](http://127.0.0.1:4322/lab/about-graph/)。

保留站点 header/footer，将两者之间的整个主区域用于粒子画布。左侧图文栏、页内标题、目录、工具条、分支导航条与可见操作提示均已移除；图文只在节点卡片中展开。页面专属布局提供深色页头页脚色板，其他页面不受影响。

节点漂移、碰撞、局部放大、驻留展开、点击保留、拖动和 Escape/空白收起继续可用。窄屏通过点击类别进入分支，点击 AtomsH 返回总览；双击空白可重置。屏幕阅读器保留页面标题和操作说明。
