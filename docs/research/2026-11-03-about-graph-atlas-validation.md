# 图文粒子星图优化与验证

后续布局已按用户要求调整为[整页画布](2026-11-03-about-graph-full-page-validation.md)，去掉左侧图文栏和页内工具条。以下保留为图文双栏版本的验证记录。

预览：[AtomsH 兴趣星图](http://127.0.0.1:4322/lab/about-graph/)。本次按用户选择，将 Capacities 的图文布局与 Cosmograph 的粒子氛围结合，继续在本地原型迭代。

## 最终体验

桌面采用左侧图文面板、右侧深色粒子舞台。17 个内容节点保持原有兴趣结构。AtomsH 固定为中心，其他节点围绕分支锚点持续缓慢漂移并相互避让。装饰粒子分成不同颜色与远近层次，桌面 680 个、手机 180 个背景粒子，另有中心微粒与关系流光。

鼠标附近的节点按距离平滑放大，最大约 1.25 倍，中心节点上限为 1.12 倍。停留 360ms 后展开图片与一行摘要，离开保留 180ms 缓冲；卡片尺寸过渡约 320ms。阅读目标保持稳定，周围节点按卡片和缩放后的真实尺寸让开。点击可保留卡片，键盘焦点可展开，Escape 或点击空白收起；鼠标拖动继续可用。

手机使用点击展开、分支切换和总览。图谱在上、图文面板在下，不拦截页面纵向滚动。数据、静态分组内容和联系入口仍由服务端提供。减少动态效果下停用持续运动和过渡；后台或离屏时取消刷新，重新可见时恢复。

## 图片与内容

全部节点都有一行摘要和图片。新增 13 张原创 SVG 插画；三张音乐封面和 EVA 封面沿用站内推荐数据来源。远程图片加载时先显示本地配图，失败时保留本地回退；节点关闭时不加载其图片。远程图片来源链接显示在内容面板中。

技术栈节点介绍的是本站实现，不把站点依赖推断为个人掌握程度。未为兴趣节点增加未经用户提供的游戏偏好、个人经历或技能声明。

## 验证

| 项目 | 结果 |
| --- | --- |
| 完整单元/组件测试 | 21 个文件、157 项通过 |
| 图谱相关测试 | 4 个文件、56 项通过；涵盖驻留、移动取消、离开缓冲、键盘、缩放、持续漂移、图片回退与生命周期 |
| 碰撞回归 | 全部 12 个子项分别在 278px、333px 舞台展开，并继续运行漂移；24 种情况的尺寸和边界检查通过 |
| Astro 检查 | 0 errors、0 warnings；保留 36 条既有 schema hints |
| 生产构建 | 44 页成功；原型 HTML 不进入生产路由或站点地图 |
| 桌面浏览器 | 17 节点，局部放大、图文卡片与内容面板联动可用；检查状态无点击区域重叠、无越界或横向溢出 |
| 390px / 320px 浏览器尺寸 | 分支展开可用；320px 的中心和叶节点展开已检查，目标保持至少 44px |
| 窄屏叶节点边缘问题 | 大卡片横向空间不足时改为上下分离；实际卡牌节点展开后的遮挡已修复，回归无重叠或越界 |
| Escape | 已展开卡片数归零 |
| 实际离屏暂停 | 状态变为 paused，连续两次观察帧计数保持为 0；恢复默认视口后重新运行 |
| SVG | 13 个文件通过 XML 解析 |

浏览器 rAF 观测约 60fps；桌面运行时指令提交约 1.1–1.6ms/帧，320px 舞台约 0.5ms/帧。此数据来自本机 Chrome 开发模式，不包括后续浏览器合成和 GPU 时间，也不是手机硬件实测结果。最终浏览器采样与截图存放在仓库忽略的 `test-results/about-graph-feasibility/` 中。

真实手机触控、移动硬件耗电和深浅主题在各设备上的最终视觉验收仍应在正式整合前复核。本轮没有替换正式 `/about/`，也没有发布操作。
