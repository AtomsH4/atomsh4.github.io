# 放大兴趣星图验证

预览：http://127.0.0.1:4322/lab/about-graph/

按用户要求将桌面图谱默认统一放大至 135%，手机放大至 112%。相机同步变换 HTML 节点、SVG 连线、Canvas 连线粒子与中心光晕；背景粒子保持全画布覆盖并随平移轻微移动。物理边界向四周扩展 30%，允许节点超出视口，画布负责裁切。

支持拖动空白平移、滚轮按光标锚点缩放、加减键缩放，双击空白或按 0/Home 恢复布局。点击或键盘聚焦边缘节点会平滑调整视角，完整展示图片与一句说明，并在碰撞避让期间保持卡片可读。手动移动和缩放接管视角。节点拖动通过相机逆变换计算世界坐标。
