# 关于页中心概念与精简节点验证

预览：[关于页](http://127.0.0.1:4322/about/)。

新增计算机、意识流、代码、存在主义、哲学五个直接连接 AtomsH 的小节点，并加入六条兴趣关联。完整图谱 35 个节点，桌面默认 27 个，手机总览 10 个。所有节点仅显示名称及可用图片；移除编号、数量、介绍、中心副标题和关键词预览。无图节点不再展开内容卡片，作品图片卡片缩短为 146px。

验证结果：

- 图谱单元测试：5 个文件、77 项通过；最后为文字增加宽度余量后，重新运行内容与几何测试，54 项通过。
- 浏览器回归：桌面层级与复位、关联高亮、320px/390px 浏览、无 Canvas、无 JavaScript 共 6 项均验证通过。最终并行构建期间关联检查触发 60 秒总超时，构建完成后单独重跑通过，未放宽断言或超时。
- 精简内容检查：每个节点的文本与其名称完全一致；中心点击后仍只有 AtomsH，无图节点不打开介绍。作品名称中的数字保留，例如荒野大镖客2。
- 关联检查：聚焦存在主义时 EVA 与关系线同步提亮；原有轻音少女—音乐关联继续正常。
- 手机总览：中心在上方，五个概念及四个主分支均可见；节点无重叠、无越界、无横向页面溢出。进入项目或技术栈后仍可沿路径返回。
- 应用内浏览器：正常动画下检查总览，五个概念、四个类别与纯名称中心均可读。
- `npm run build`：0 errors、0 warnings、36 项既有提示，44 页构建成功。修正了回归测试中读取 `offsetHeight` 时遗漏的 HTMLElement 类型标注。
- `git diff --check` 通过。未修改依赖或发布。

## 连线无文字与按需配图

按用户后续要求删除关系线的 SVG 文字元素及坐标更新逻辑，仅保留连线与高亮。所有节点默认以名称标签展示，不渲染图片；四张指定作品图片在节点展开时加载和显示，收起或复位后移除。移除默认缩略图样式，碰撞尺寸按文字节点计算，展开时继续使用实际图片卡片尺寸。

验证：5 个单元测试文件、77 项通过；6 项浏览器回归通过，检查默认图片为零、关系线文字为零，并逐一展开四张本地图片后确认其解码成功，复位后图片数量恢复为零。320px/390px、关联高亮、无 Canvas 与无 JavaScript 回退均通过。生产构建完成 44 页。
