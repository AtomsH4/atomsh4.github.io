# 推荐页实物陈列改版

日期：2026-11-15。用户已同意本轮建议中的实物陈列方案，并授权实现与验证。

## 目标

保留米色分类弥散背景、现有内容、来源署名、深链、键盘和拖动导航。将舞台改成一件主作品与左右两件邻项，以清晰的厚度、材质分层和统一投影增强实物感。

## 设计

- 音乐与影视继续使用 disc 表现，但升级为完整方形唱片套与半露出的 CD。纸套使用哑光封面，CD 分离印刷层、银色外圈、中心环和边缘，虹彩限制在反射区域。
- 书籍使用有倒角的封面与封底、带标题的书脊、纸张边缘纹理。厚度按作品稳定变化。继续只展示闭合书本。
- 主作品水平偏转约 20 度，邻项缩小、后退，避免封面与大段信息重叠。桌面和紧凑布局均最多三件作品。
- 使用柔和主光、补光与条形环境反射。以模型后方的透明阴影接收面统一悬浮投影，随按需渲染更新；移除位于原点且仅渲染一帧的水平接触阴影。
- 减弱色晕和玻璃卡片。移动端为元数据、分类和舞台分配独立安全区域；不出现横向溢出。

## 加载与降级

本地检查发现开发服务请求旧版预构建依赖时返回 504，推荐 React 岛因静态依赖整个 Three.js 图而无法激活。显式预构建 3D 依赖，并按需导入舞台。将纯封面生成代码与 Three.js 纹理加载代码分离，使 HTML/CSS 降级和页面交互可以独立激活。舞台模块、渲染初始化或上下文失败时保留可交互的 CSS 实物视图。

## 验收

构建与现有单元测试通过；验证分类、深链、前后切换、背景拖动、作品旋转、减少动态效果、WebGL 失败降级。检查桌面、390px 和窄屏截图，确认主体完整、标题不遮挡、来源可访问。保持 GitHub Pages 现有部署方式，本轮不创建额外托管站点。
