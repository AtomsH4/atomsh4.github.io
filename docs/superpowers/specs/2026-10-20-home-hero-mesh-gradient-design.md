# 首页 Hero Paper Mesh Gradient

用户已选择并要求实现上一轮建议：首页 Hero 接入 Paper Mesh Gradient，保留现有蓝紫色毛玻璃风格，动效缓慢，完成后提供本地预览。

## 设计

仅在首页 Hero 的圆角边界内添加装饰性 canvas。沿用淡蓝、薰衣草紫与少量柔粉；文字侧叠加半透明遮罩，维持标题、介绍和按钮的可读性。保留现有布局、内容、玻璃边框、阴影和其他页面。

使用固定版本的 `@paper-design/shaders` 原生接口，按需加载并挂载 Mesh Gradient，无须为背景引入额外 React 组件。速度取默认值的约十分之一。装饰层不接收指针事件，使用 `aria-hidden`。

按系统浅色/深色主题更新 shader 色板和遮罩。Hero 不可见或文档隐藏时暂停。减少动态效果开启时不初始化 WebGL，使用现有静态 CSS 渐变；运行期间切换偏好也应生效。模块加载失败、WebGL 初始化失败或 context 丢失时返回静态背景。

限制渲染像素数量，随容器自动调整尺寸。元素断开时释放 GPU 资源、观察器和媒体查询监听。
