# 首页 Hero Paper Mesh Gradient

用户已选择并要求实现上一轮建议：首页 Hero 接入 Paper Mesh Gradient，保留现有蓝紫色毛玻璃风格，动效缓慢，完成后提供本地预览。

## 设计

仅在首页 Hero 的圆角边界内添加装饰性 canvas。沿用淡蓝、薰衣草紫与少量柔粉；以低对比的不规则云雾色团自然融合，避免条带、直线分区和线性渐变。调整 shader 扭曲与旋涡，使用等比完整色场，防止横向裁切后形成条带。远层弥散柔光、中层流动的六色渐变与近层浅色薄雾分别采用 48px、18px、14px 模糊，通过径向透明遮罩自然融合；近层和远层为轻量 CSS 光场，中层沿用单个 canvas。云雾主要集中于右侧，文字附近保持低对比。首页底色和外围光晕进一步调淡；其他页面保持原有配色。静态回退也使用淡色径向光晕。保留现有布局、内容、玻璃边框和阴影。

使用固定版本的 `@paper-design/shaders` 原生接口，按需加载并挂载 Mesh Gradient，无须为背景引入额外 React 组件。主色场速度使用默认值的 48%，中层 canvas 以 18 秒单程时长整体漂移与缩放，前后两层分别以 14 秒和 20 秒的单程时长往返漂移、缩放与轻微旋转。移动幅度进一步加大，使用负动画延迟从流动中段开始，避免初次打开时停留在缓动端点；保留柔和边缘与淡色背景。扩展装饰层的裁切余量，确保移动和缩放不露出 canvas 边界。装饰层不接收指针事件，使用 `aria-hidden`。

首页顶部小标签和名句使用更清楚的主题派生色，确保浅色云雾和不同动画时刻经过文字下方时仍然可读；正文和标题层级保持不变。

按系统浅色/深色主题更新 shader 色板和遮罩。Hero 不可见或文档隐藏时统一暂停 WebGL 与 CSS 云层，重新可见时恢复。减少动态效果开启时不初始化 WebGL 并取消 CSS 云层动画，使用现有静态 CSS 渐变；运行期间切换偏好也应生效。模块加载失败、WebGL 初始化失败或 context 丢失时返回静态背景并停止 CSS 云层。

限制渲染像素数量，随容器自动调整尺寸。元素断开时释放 GPU 资源、观察器和媒体查询监听。
