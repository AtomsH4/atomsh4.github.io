# 兴趣图谱图文布局与粒子交互

用户已选择 Capacities 的图文布局与 Cosmograph 的粒子氛围，并要求节点自行移动碰撞、跟随鼠标放大、停留后展开一行信息与图片。继续更新独立本地原型 `/lab/about-graph/`。

桌面采用左侧内容面板、右侧深色粒子图谱。左侧显示当前节点的图片、一行摘要、路径和相关入口；鼠标停留约 360ms 后，图中节点平滑展开图片和摘要，并同步内容面板。鼠标移动时附近节点按距离平滑放大，离开时回到原尺寸。点击或键盘选择可以保留节点卡片，Escape 收起。手机以点击触发相同信息，保留分支总览与页面滚动。

除固定中心 AtomsH 外，节点在各自分支附近持续缓慢漂移，使用实际尺寸的碰撞约束。节点卡片展开和局部放大时更新碰撞尺寸，让邻居自然让开。悬停或阅读当前节点时固定该节点，避免移动目标逃离鼠标。粒子采用多层远近、微弱星云与细线流光，独立于 17 个内容节点。

所有节点具有一行摘要和本地原创 SVG 配图，已有音乐/EVA封面及可核实的官方作品图可以用于对应节点；远程图片失败回退到本地配图。图片不阻止文字与交互。尊重减少动态效果，离屏和后台暂停，卸载清理。静态 HTML 仍提供完整兴趣列表和联系入口。

碰撞按当前实际矩形尺寸与缩放计算，包含舞台边界的可用空间。横向空间不足时改为纵向避让，避免大卡片把邻居挤在边缘后仍然重叠。实际内容配图为 13 张原创 SVG，以及已有的三张音乐封面和 EVA 封面；本轮不新增第三方素材副本。

验证：新增驻留控制、持续漂移、碰撞尺寸更新、局部放大、Escape/点击行为与生命周期检查；在 1280px、390px、320px 浏览器尺寸下检查展开卡片的边界、可读性和实际帧率。真实手机性能单独说明。用户本次选择与具体交互指令构成实施授权。
