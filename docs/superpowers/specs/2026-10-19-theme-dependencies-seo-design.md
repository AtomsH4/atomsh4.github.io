# 按检查报告修复主题、依赖与 SEO

用户已确认检查报告中的前三项实施范围，并要求完成后运行测试验证。

主按钮使用独立的背景、边框与文字主题变量，避免深色主题的正文强调色改变按钮背景后仍保留白字。浅色与深色的普通、悬停和焦点状态都应保证文字可读。

依赖通过兼容版本更新修复审计发现的问题，保留现有框架主版本，更新锁文件并检查所有平台的 sharp 可选包。最终验收包括全依赖 `npm audit`。

新增共享 SEO head 组件，供两个布局调用。页面显式传递摘要；规范网址从部署站点与路径生成，去掉查询参数和锚点并统一目录末尾斜杠。输出 Open Graph、Twitter 分享信息和本地默认分享图。文章复用标题、摘要、发布时间与作者信息输出 BlogPosting JSON-LD，序列化时转义 `<`，防止内容结束 script 标签。不存在真实更新时间时不虚构 dateModified。404 设置 noindex。

通过 Astro 官方 sitemap 集成生成站点地图，排除 404、旧仓库路径与迁移跳转地址；robots.txt 与 head 提供 sitemap 入口。默认分享图和 favicon 为静态品牌资源。

验证顺序：依赖审计与单元测试；Astro 检查和生产构建；SEO 元数据、站点地图排除规则及浅色/深色按钮对比度的浏览器检查；完整端到端测试。首轮报告发现的外部封面与表格时序不稳定测试如失败，仅针对失败项复核并如实记录。
