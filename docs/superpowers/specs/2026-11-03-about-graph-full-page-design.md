# 整页兴趣星图

用户已认可粒子风格，要求画布填满 header 与 footer 之间的页面，去掉左侧信息栏和其他内容。按该明确指令继续更新本地原型。

新增独立页面布局，复用站点 header/footer；主内容取消宽度限制、外边距、边框与圆角，按剩余视口高度展示粒子画布。页内标题、信息栏、目录、工具条及提示统计全部移除，只保留屏幕阅读器标题和操作说明。页头与页脚沿用原组件及导航，通过页面作用域色板适配深色星空。

桌面默认显示 17 个节点，保留漂移、碰撞、局部放大、图文展开、点击保留、拖动和 Escape/空白收起。手机点击类别进入分支，点击 AtomsH 返回总览，不再显示独立分支导航条；双击画布空白可重置布局。卡片与图片继续在节点本身展示。

常规屏幕画布填充可用视口；900px 起展示完整图谱、画布最低 420px；小于 900px 的手机和平板采用分支浏览、最低 560px。短屏允许页面自然滚动，避免节点卡片被挤压。静态分组回退继续可读，必要时在画布区域内滚动。验证桌面与手机的边到边覆盖、header/footer、图文卡片边界及构建。

## 放大视角调整

用户进一步要求画布内容更大，并接受内容超出边框。桌面初始视角统一放大至 135%，窄屏至 112%，同步放大节点、字体、连线与语义粒子；物理世界在视口外保留 30% 余量，不再强制将所有节点压入可见区域。画布裁切外围内容，保持页面本身没有横向溢出。

鼠标或笔拖动空白平移，滚轮按指针位置缩放，加减键也可缩放，双击空白、0 或 Home 键复位。节点拖动使用相机逆变换。点击或键盘聚焦边缘节点时平滑展示完整图文，手动平移、缩放或拖动节点接管视角；悬停展开保持原位。手机保留原有类别浏览及页面触摸滚动。减少动态效果时直接调整视角，无持续动画。
