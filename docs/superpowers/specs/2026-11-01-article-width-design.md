# 内容页阅读宽度调整

用户已批准「正文 864px，代码、表格和大图最多 1088px」的方案。

## 设计与范围

- 博客与随笔的标题、摘要、正文段落统一居中，最大宽度由 44rem（704px）调整到 54rem（864px）。保留当前正文的字号和 1.8 倍行高。
- 文章使用共享的三轨 CSS 网格，正文放在中间轨，顶层代码块、表格容器、figure 与独立图片段落可跨至完整的 68rem（1088px）宽内容区。两种宽度共用中心线，无需脚本测量或改变内容数据。
- 嵌套在列表、引用中的媒体继续遵循所在容器宽度，避免破坏缩进。宽内容区始终受页面可用宽度限制；代码和表格在小屏上局部横向滚动。
- 内容页的导航、主体、页脚共用响应式边距：手机至少 20px，平板 24–32px。首页和列表页沿用原布局。
- 把两种文章页重复的阅读样式合并到独立样式文件，统一管理标题、网格、代码、图片和图注。
