# 内容页阅读宽度调整

用户确认内容页加宽，并批准统一文章内部宽度。最终方案为「全站容器最多 1152px，标题、正文、表格、代码和图片统一遵循 864px 文章宽度」。

## 设计与范围

- 博客与随笔的标题、摘要、正文段落统一居中，最大宽度由 44rem（704px）调整到 54rem（864px）。保留当前正文的字号和 1.8 倍行高。
- 文章采用普通居中块级容器，宽度统一由 `--content-prose: 54rem` 控制。删除三轨 CSS 网格、跨列规则和 `--content-media` 变量，子元素自然遵循文章宽度。
- 嵌套在列表、引用中的媒体继续遵循所在容器宽度，避免破坏缩进。文章始终受页面可用宽度限制；超宽代码和表格在自身容器内横向滚动。
- 图片按原始尺寸居中显示，超过可用宽度时等比例缩小；图注遵循正文行宽。
- 内容页的导航、主体、页脚共用响应式边距：手机至少 20px，平板 24–32px。首页和列表页沿用原布局。
- 把两种文章页重复的阅读样式合并到独立样式文件，统一管理标题、段落间距、代码、图片和图注。
