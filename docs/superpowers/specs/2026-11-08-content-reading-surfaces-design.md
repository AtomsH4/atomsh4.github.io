# 博客与随笔阅读底板

用户于 2026-11-08 确认改善内容可读性，并明确背景覆盖全宽、内容保持原宽；上下区域的调整指缩小为 header 和 footer 留出的间距。最终使用全宽柔和底色、居中内容和更紧凑的上下留白。

## 设计

- 浅色底色使用 56% 不透明白色，深色底色使用 62% 不透明深灰蓝色，允许少量外围渐变自然透入。
- 博客、随笔详情页取消大圆角卡片的边界、内边框和投影，改用 `main::before` 绘制全宽底色。底色铺满左右两侧，上下渐变恢复为上一版的 `clamp(10rem, 24vh, 20rem)`，即 160–320px。
- 遮罩仅作用于背景伪元素，正文、链接、焦点提示和图片浮层不受影响；不在长文背景上使用大面积模糊。标题和正文继续直接位于现有 `main` 内。
- 顶部 Blog／Notes 小标签混合 85% 主题强调色与 15% 正文色，保证渐变拉长后在起始区域仍有足够文字对比度。
- 背景所在的 `main` 显式使用 `width: 100%`、`max-width: none` 和 `margin-inline: 0`，覆盖视口宽度。标题、摘要和正文继续使用 `--content-prose: 54rem` 最大宽度并水平居中；表格、代码和图片继续遵循正文宽度。
- 底板保留 `--page-gutter` 对应的 20–32px 手机及窄屏水平留白。1440px 与 1920px 视口下背景分别覆盖 1440px 和 1920px，而正文均保持 864px；390px 下正文保持 350px，320px 下保持 280px。
- 文章主区域上下外边距均缩为 8px，文章页 footer 的顶部外边距缩为 8px；主区域上下内边距缩为 16–24px。实测 header 到背景为 8px、背景到 footer 为 16px；header 到内容为手机 24px／桌面 32px，正文末尾到 footer 为手机 32px／桌面 40px。
- 随笔索引页的整个列表使用一块半透明底板，内侧留白为 `clamp(1.25rem, 3vw, 2rem)`。条目沿用透明背景、分隔线和现有链接交互。
- 博客索引页的卡片使用同一组半透明底色。两个列表的底板去掉可见边框和常态投影，使用 24px 背景模糊，并继续加强次要文字颜色。悬停与键盘焦点提示沿用现有规则。
- 不改变首页、项目页、推荐页、兴趣图谱、内容和导航，也不增加脚本或依赖。

## 验证

运行生产构建、已有阅读布局、表格、随笔、博客图片浮层及 SEO／主题检查。通过浏览器检查两个索引页及代表性文章在 320、390、768、1440px 和深浅主题下的横向溢出、正文宽度、图片及长代码滚动，并检查正文和次要文字在实际底色上的对比。
