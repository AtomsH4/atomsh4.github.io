# 关于页粒子图谱本地原型

用户已确认选型报告，按 Astro + React + d3-force、HTML/SVG 节点关系和 Canvas 2D 装饰粒子制作可运行原型。

## 范围与交互

使用报告中的全部 17 个节点。AtomsH 固定为根；桌面默认显示两级完整图谱，类别可展开或收起，节点可拖动并回归，悬停或键盘聚焦高亮路径。点击节点更新详情与站内链接，重置恢复总览。手机默认显示根和四类入口，点击类别后显示当前路径和子项，另设明确的分支与总览按钮。

沿用站点浅色、深色与蓝紫色系。节点文字由 HTML 呈现，Canvas 不接管交互；粒子沿关系流动并在中心周围形成微弱聚集。所有节点使用原生按钮，提供可见焦点，手机保留至少 44px 高的目标。无 JavaScript 时显示完整分组列表与联系入口。

## 架构与生命周期

内容、可见性与路径函数、物理布局、绘制运行时和 React 状态分别实现。内容数据不交给 d3 直接修改；布局使用真实 DOM 尺寸作为碰撞和边界依据。每帧通过 ref 更新位置与连线，React 只管理交互状态。

统一 requestAnimationFrame 调度物理迭代和粒子。离屏、后台暂停；减少动态效果时一次求解并保持静态；Canvas 不可用时继续使用 HTML/SVG。卸载时取消帧、停止模拟并移除观察器和监听。

## 本地路由与验证

原型路由为 `/lab/about-graph/`，仅 Astro 开发模式提供，不进入生产构建、导航或站点地图。正式 `/about/` 保持现有内容，待原型评审后再替换。

验证包括状态/布局单测、Astro 检查与生产构建、真实浏览器桌面和 390px/320px 视口交互、标签避让、主题、减少动态效果、离屏暂停与数值帧率观测。模拟手机尺寸只证明本机浏览器表现，不宣称真实手机硬件性能。
