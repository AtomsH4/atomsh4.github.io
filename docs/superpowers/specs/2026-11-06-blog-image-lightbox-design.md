# 博客图片放大浮层

用户已于 2026-11-06 确认：点击博客图片在当前页居中放大，点击放大后的图片关闭，支持手机和 Esc，并回到原阅读位置。

## 范围与交互

- 对所有博客正文图片生效，包括现有 5 篇文章中的 8 张 SVG 配图。
- 图片打开原生 `dialog`，遮罩覆盖页面，图片保持比例并适应可见视口；浮层只展示图片。
- 点击浮层图片、空白遮罩或按 Esc 关闭。键盘可用 Enter、空格打开和关闭图片。
- 打开期间锁定背景滚动；关闭后恢复图片入口焦点和原阅读位置。打开过程不改变文章 URL，也不打开新标签页。
- 博客正文采用渐进增强：客户端把图片链接或独立图片转换成有语义的按钮。关闭 JavaScript 时保留现有正文及原图链接。
- 将现有图注的“查看原图”提示同步为放大及关闭提示。

## 实现选择

使用独立 Astro 组件封装原生 `dialog`、图片入口增强及样式，只接入博客正文模板。浏览器管理模态焦点和 Esc；组件管理图片来源、替代文本、背景滚动及关闭后的阅读位置。

相比手写遮罩，原生 `dialog` 提供模态焦点管理；相比第三方灯箱，无需新增依赖，也无需画廊或工具栏。

## 验收

- 生产构建及 Astro 检查通过。
- 浏览器检查覆盖全部配图在 390px 和 1440px 视口下的加载、浮层打开、点击图片关闭、文章 URL、阅读位置及焦点恢复。
- 检查 Esc、Enter、空格、遮罩关闭和背景滚动锁定，确认禁用 JavaScript 时原文仍可读。
- 保持现有文章宽度、代码块、表格及随笔阅读布局检查通过。
