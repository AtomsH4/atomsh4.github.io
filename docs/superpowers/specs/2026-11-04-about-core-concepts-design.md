# 关于页节点与布局

## 当前内容

AtomsH 周围保留音乐、编程、二次元、游戏四条兴趣分支，以及存在主义、哲学两个概念节点。按用户最新要求删除意识流、计算机、代码及其相关连线。完整图谱 31 个节点，桌面默认 21 个，手机总览 7 个。

R&B、摇滚、流行改为静态文字节点，没有配图、图片预览或子节点展开行为。按用户最新要求移除我表示理解、给自己的情书两首歌曲节点，以及卡牌、解谜节点和相关连线。

编程下保留技术栈、项目、算法、深度学习、ACM。技术栈子项为 React、Python、Electron、NodeJS、MySQL、C++。ACM 点击后按顺序展开图论、数论、数据结构、动态规划四个分类，替换原先的 BFS 与最短路题目节点。项目下仅保留 Cherry Studio。项目和算法采用“项目｜→”“算法｜→”分区按钮，右侧仅显示向右箭头的独立链接，分别进入 `/blog/` 的项目开发文章、`/notes/` 的算法笔记；节点按钮继续负责选择与类别展开。

类别、概念和中国作品使用中文，游戏恢复为荒野大镖客2、极乐迪斯科中文名称；K-ON! 保留英文专名，Eva 按用户指定大小写显示。深海使用海上落日与彩色海浪的电影剧照，来源元数据保留在 `graph-presentation.ts`。

## 显示与交互

默认只显示名称，项目和算法另有仅显示向右箭头的跳转区域，去向由悬停提示和辅助标签说明。动画和游戏作品只在展开时显示配图。图片卡片维持 208×146px，中心维持 88px 浅色圆形和 AtomsH 名称。

不显示左侧圆点、节点编号、计数、短句介绍、中心副标题或连线文字。保留节点拖动、画布平移、缩放、复位及无 Canvas / 无 JavaScript 回退。导航锚点随节点的相机变换和拖拽更新位置，支持键盘访问与站点 base path。跳转区域覆盖节点完整高度，手机实际点击范围不小于 44×44px，悬停、按下和键盘聚焦均有反馈；左侧继续负责选择与子项展开。

## 布局

桌面将四个分支分别展开到四个方向，让作品和编程子项拥有独立空间。初始缩放从 1.35 调整为 1.2，节点之间的碰撞留白从 8 增加到 20 世界坐标像素。默认总览须完整位于画布内，技术栈展开后六个子项仍可见。

两个概念保留在中心周围约 130–148 世界坐标像素处。手机总览重新排列两概念与四分支，避免删除节点后留下空的排位。分支内部保留祖先路径和两列子项，根据可用高度调整行距；碰撞留白增加到 12 世界坐标像素。

## 验证

检查三个音乐风格节点在停留、键盘聚焦、点击后均不展开或挂载图片，已删除的歌曲与游戏类型节点、连线无残留。核对桌面默认边界和技术栈、320px/390px 手机总览及各分支、博客与笔记跳转、无 Canvas 与无 JavaScript 回退，并运行图谱单元测试和生产构建。
