## 已确认的体验

进入首页后，全屏居中书写大幅连笔花体 `AtomsH`。等待实际书写动画结束，停留 320ms，再用 1200ms 将花体等比移动到首页标题的真实位置。花体全程保持不透明，背后的全屏蓝紫底色独立淡出，显露首页；同一时长和缓动将开场画面的裁切范围收至卡片圆角边界，避免落位时溢出笔画突然消失。点击区域始终覆盖整个屏幕。移动结束时准确衔接同一字形的静态标题，不重新书写，也不出现两个重叠标题。

首页 Hero 左上角放置较大的永久花体 `AtomsH`，以轻微负位移使顶部和左侧笔画超出边框，由卡片的 `overflow: hidden` 和圆角边界隐藏。英文引语去掉两端引号，采用 Courier 风格的等宽打字机字体，定位在卡片右下角，保留舒适内边距。文字区域上限为 44ch，使用均衡换行以形成两行排版；窄屏按可用宽度继续自然折行。手机也沿用两角构图，不产生横向滚动。顶部小标签和“浏览博客”按钮继续移除。

## 实现边界

- 使用本地 SVG 字形和手工书写轨迹，显示填充的书法笔画；不把字体外轮廓描边当成书写，不依赖访客下载远程字体。
- 花体采用更简洁的 Allura 开源字形，保留清楚的大写和字母连笔，并记录来源与 OFL 许可。s→H 的细笔接入与 H 左下回弯构成连续曲线，粗细自然过渡；连接和主笔沿同一轨迹书写。仅修改首页标题展示，站点品牌、网址和其他页面身份仍沿用现有配置。
- 每次打开首页时开场播放一次；移动结束后隐藏全屏开场层，显示落点处的静态字形。页面不循环回到开场。
- 开场不显示跳过按钮，点击屏幕任意位置即可跳过，保留 Esc、Tab 和滚轮。跳过和正常结束均清理事件并恢复页面滚动；保留原有语义标题与键盘访问。减少动态效果时直接进入原首页。禁用 JavaScript 时 CSS 仍自动淡出，不留下永久遮挡。
- 全屏开场适配 320px 手机、桌面和深浅主题，不裁切花体长笔画。根据源与目标 SVG 的实际位置计算移动与等比缩放；开场与落点使用明确一致的 SVG 纵横比，不对 SVG 单独限制高度，避免交接时尺寸跳变。绘制精确落位帧后再显示静态标题。移动中改变窗口尺寸时直接在当前正确位置完成衔接。保留滚动条空间，避免退出时横向跳动。
- 复用现有云雾生命周期，不新增动画框架或修改依赖。其他正在进行的关于页工作不属于本任务。
