# AtomsH 首页签名开场

用户已选择个人首页的大幅签名书写方案，并确认开屏文字为 `AtomsH`。

## 已确认的体验

首页第一屏以居中的大幅连笔花体 `AtomsH` 为视觉主体，沿用现有浅蓝紫云雾和玻璃材质。签名在约 2–3 秒内按笔画顺序写出；完成后保留字样，原有个人博客标签、引语和浏览博客入口轻轻浮现。直接向下滚动即可阅读原有内容，不新增阻挡访问的加载页。

## 实现边界

- 使用本地 SVG 字形和手工书写轨迹，显示填充的书法笔画；不把字体外轮廓描边当成书写，不依赖访客下载远程字体。
- 花体基于 Great Vibes 开源字形，保留来源和 OFL 许可记录。仅修改首页标题展示，站点品牌、网址和其他页面身份仍沿用现有配置。
- 签名在每次打开首页时播放一次，完成后静止。普通内容不随动画反复隐藏。
- 保留语义化一级标题、原有链接和键盘访问。减少动态效果时直接展示完整签名和简介；禁用 JavaScript 时仍能完整显示与导航。
- 首屏高度接近可用视口；320px 手机、桌面以及深浅主题均需清晰，不裁切花体的长笔画或产生横向溢出。
- 复用现有云雾生命周期，不新增动画框架或修改依赖。其他正在进行的关于页工作不属于本任务。

## 验证

运行 Astro 类型检查和生产构建，执行现有首页、手机导航与深浅主题按钮的定向端到端检查。检查签名在播放中与播放后均可见、最终笔画完整、320px/390px/桌面无溢出，以及减少动态效果和 JavaScript 禁用时的完整内容与可用链接。通过本地预览交付效果。
