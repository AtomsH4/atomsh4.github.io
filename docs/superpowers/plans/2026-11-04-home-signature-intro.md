# AtomsH 首页签名实施计划

依据已确认的 [设计](../specs/2026-11-04-home-signature-intro-design.md) 实施。

1. 将 `AtomsH` 的花体字形转换为本地 SVG 路径，制作逐笔显现的书写轨迹，并记录字体来源。
2. 新建首页专用签名组件，使用原生 SVG/CSS 完成一次性的约 2–3 秒书写。
3. 将首页首屏调整为大幅居中构图，衔接现有云雾、个人标签、引语与博客入口；适配手机、深浅主题与减少动态效果。
4. 运行构建和首页相关的既有检查，实际查看播放过程和各视口下的完成状态，修复观察到的问题。
5. 打开可用的本地预览并记录验证结果。

## 完成与验证

- 已接入六个矢量字形和九条手工轨迹，书写于 2.82 秒完成；静态像素核对确认轨迹完全覆盖原始字形。
- 已完成居中近满屏首屏、简介渐入、深浅主题、减少动态效果和无 JavaScript 回退，未新增运行时依赖。
- `npm run build` 通过，Astro 0 错误、0 警告，保留既有内容 schema 弃用提示和推荐页包体积提示。
- 现有首页入口与深浅主题按钮 3 项定向检查通过。
- 临时专项检查 4 项通过：指定时间点的逐笔显现和完成静止；1440/768/390/320px × 深浅主题的内容与边界；减少动态效果与立即键盘访问；禁用 JavaScript 的完整首页。
- 自动检查中的软件 WebGL 渲染曾出现超时；专项检查改用无 GPU 环境检查签名与背景回退。正常 WebGL 云雾和真实书写另在应用浏览器中查看，控制台无错误。
- 应用浏览器已核对正常桌面、390px/320px 手机、导航展开与 Esc 收起；修正有实体滚动条的 320px 视口溢出后，页面宽度与可用宽度均为 305px。
- 本地开发预览：`http://127.0.0.1:4322/`，已保留首页浏览器页签。截图和临时检查位于忽略目录 `test-results/home-signature/`。

## 2026-11-05 大写与连笔修订

用户要求 A 使用清楚的大写写法，并使各花体字母连笔，尤其是 s 与 H。改用带横画的 A.ss02 变体，重新安排后续字母的位置，添加 s 到 H 的细笔连接，并将 H 的主笔顺序改为从连接处进入回旋。A 分为三条书写轨迹，整体仍在 2.82 秒完成。视框和遮罩扩展以保留 A 左下方的起笔。

静态像素核对确认六个字母合为一个连接区域，所有填充笔画均被动画遮罩完整覆盖。`npm run build` 通过；应用浏览器已核对实际书写过程、桌面完成状态和 320px 手机排版。更新后的截图为 `test-results/home-signature/capital-connected-desktop.png` 与 `capital-connected-mobile.png`，预览页签已恢复桌面并保留。

## 2026-11-05 独立开场与原首页过渡

用户要求开头展示花体，之后自然过渡到原页面。首页恢复原先的左对齐标题、云雾 Hero 高度、引语、博客入口和内容列表；大写连笔 `AtomsH` 移至独立全屏 `HomeIntro`。书写 2.82 秒，停留至 3.15 秒，随后以 800ms 淡出和轻微缩放上移露出原首页。

使用原生 CSS 完成自动退出，轻量自定义元素负责跳过、滚动恢复、偏好切换和生命周期清理。支持跳过按钮、Esc、Tab 和滚轮；减少动态效果直接进入首页，禁用 JavaScript 仍可由 CSS 退出。

验证：`npm run build` 通过，Astro 0 错误、0 警告；新增的 4 项端到端检查全部通过，覆盖自动过渡与后续导航、按钮/Esc 跳过、减少动态效果的初始与实时切换、禁用 JavaScript 的 CSS 自动退出。应用浏览器确认全屏开场不露出导航和内容，结束后原首页标题为 `AtomsH4`、Hero 恢复约 386px 高度，页面滚动已恢复。过渡后的截图为 `test-results/home-transition/page-after-intro.png`。
