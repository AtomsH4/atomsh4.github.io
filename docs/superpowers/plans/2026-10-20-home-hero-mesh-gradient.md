# 首页 Hero Mesh Gradient 实施清单

用户已批准首页 Hero + Paper Mesh Gradient 方案并要求直接制作预览。

1. 安装固定版本的 Paper Shaders，核实 ShaderMount 与 Mesh Gradient 的实际 API。
2. 新建首页专用 Astro 装饰组件及生命周期脚本，处理按需加载、主题、可见性、减少动态效果和 WebGL 降级。
3. 在首页 Hero 挂载组件；为 Hero 增加局部堆叠上下文与圆角裁切，保持当前布局和内容。
4. 检查桌面和手机视觉效果，调节蓝紫配色、遮罩和慢速参数。
5. 运行生产构建与现有首页/主题定向检查，验证运行时动效与降级，记录结果并打开预览。

全部完成。固定 Paper Shaders 0.0.81，首页按需加载的 shader 代码约 21 KB（压缩前），控制脚本约 4 KB。构建和 4 项现有定向检查通过，生产构建的 11 项运行时检查通过，结果记录在对应设计文档中。

视觉修订：按用户提出的“柔和、不要线形”反馈，移除 Hero 静态背景与 shader 遮罩中的线性渐变。shader 改为完整等比色场与右侧云雾色团，使用 40px 模糊、多团径向透明遮罩和更柔和的色板自然融合边界。保留慢速、主题适配与降级行为。

2026-10-21 层次修订：按用户反馈调淡首页底色与光晕，shader 改用六色浅色板；后方大范围柔光、中间流动色团和前方浅色薄雾采用不同模糊尺度，增强空间层次。继续使用一个 canvas 与默认 10% 的动画速度；云团集中右侧，保持文字区域清晰。

本轮构建与 4 项现有首页/主题检查通过。已检查深浅主题、桌面/手机、3 个动画时刻的实际文字背景对比度，并调整小标签与名句的主题派生色；普通文字最低 4.60:1。

2026-10-21 动效可见性修订：针对“云雾变化不明显”，主色场速度由 0.1 调至 0.28，形变强度调至 0.36；前后云层加入 22 秒和 30 秒的不同方向漂移、缩放和旋转。CSS 云层跟随组件可见性、文档可见性、减少动态效果与 WebGL 降级统一暂停或恢复。名句对比色进一步加强，保证云层移动到文字下方时可读。

本轮构建、桌面与 320px 小屏的真实动效及暂停/恢复检查通过；经过至少 5 秒观察的截图像素对比确认云团在变化。深浅主题与 3 种视口下的多个云层位置对比度检查通过，普通文字最低 4.90:1。当前浏览器预览已刷新。

再次增强动效：按“再明显一点”的反馈，主色场速度调至 0.48、形变强度调至 0.48。前后云层位移幅度约翻倍，单程时长缩短至 14 秒与 20 秒；中层 canvas 加入 18 秒的整体漂移和缩放。通过负动画延迟避免开头的近乎静止阶段，略减中层模糊并增大裁切余量，沿用淡色板与所有暂停/降级行为。

本轮构建、三层 CSS 与 WebGL 动效、暂停/恢复与降级检查通过。深浅主题与 3 种视口的多个云层位置对比度检查通过，普通文字最低 4.80:1；预览已刷新。
